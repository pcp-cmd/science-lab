## 可以带走的四个认识

1. 验证方案要匹配实际预测任务。随机缺失、内部缺口和边缘外推可能给出很不同的误差。
2. 先平均参数，再计算风险，不一定等于先计算风险，再取平均。偏差方向也不能一概而论。
3. 分布误差小和平均等待时间误差小，需要不同保证。后者还取决于长尾。
4. 数值方法未能给出证书，不等于数学对象有错。有限精度可能让严格正数的包围区间包含零。

这些结论的具体数字都依赖各单元列出的模型和条件，不是对真实物种、地图或观测的直接预测。

## 怎么使用

每个单元的 README 提供运行命令和适用边界。完整中文教程保留必要推导、参考文献和练习。先运行最小程序，对照保存输出，再修改一个参数，尝试解释变化。

- `random-environment/`：E01 使用 NumPy、SciPy；E02 使用 Python 标准库。
- `markov/`：列出的精确验证命令只用 Python 标准库；可选浮点程序另需 NumPy、SciPy。
- `spatial-validation/`：最小实验使用 NumPy。
- `transit-boundary/`：只用 Python 标准库。
