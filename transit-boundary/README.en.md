# Why can a positive denominator still prevent certification?

## Question and input

The stellar radius is normalized to 1. The planet's radius is k=1/100. The distance between the centers is z=99/100+2⁻¹²⁰. The intensity is p(r)=1−cr², with c=7/10. This is the special case α=2.

The offset is extremely small. Ordinary binary64 cannot retain it as a distinct offset at this location.

The program first calculates the positive denominator (z+k)²−1 exactly. It then encloses the denominator on a binary grid with spacing 2⁻⁹⁶. Outward rounding gives [0,2⁻⁹⁶]. An interval containing zero does not imply that the original number is zero. A certification method that divides by this interval may have to stop.

## An independent check

For quadratic intensity, disk moments give the exact integral of the polynomial over the whole planetary disk. A thin annulus bounds the small part outside the star. Its thickness is ε=z+k−1.

Let d=1−c/2. Let J be the binary64 intensity value generated by the fixed expression in the code. Then:

```text
R_full = 10^6 k² [1 − c(z² + k²/2) − J] / d
|R_J − R_full| ≤ 10^6 [(1+ε)² − 1] max(|J|, |1−J|) / d
```

Every decision uses exact `Fraction` arithmetic. The printed decimals are outward-rounded displays. The underlying rational interval has width below 4×10⁻³⁰ ppm. Here, SAFE means only that the interval lies within [−1,1] ppm.

## Limits

- This is not the complete annular or half-angle implementation. It does not load or test PyTransit.
- It does not verify general intensity laws or the full parameter domain.
- It does not rerun the historical 85 checks or 72 certificates.
- The code fixes how J is generated. J is not an output obtained from a real software run during this check.
- This is a high-precision boundary-geometry teaching example. It does not establish production speedups or benefits for real observations.

The current check only confirms that this small program reproduces its saved output. No new research experiment was added. Disk moments, area bounds, and rational arithmetic are established tools. No methodological novelty is claimed.
