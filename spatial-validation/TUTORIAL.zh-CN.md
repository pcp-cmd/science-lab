# 第一部分：验证误差究竟在回答什么问题？

这是一个完整、可运行的中文研究教学单元，面向有少量 Python 基础、尚未系统学习高等数学的读者。可以先运行代码看结果，再按需要阅读后面的公式。这里不会把任何内容标成你已经掌握。

本单元的结论很具体：**当目标是补齐连续的内部缺口时，随机五折验证估计的是更容易的任务；把边缘缺口混进分块验证，又可能估计得偏难。即使最近观测距离的分布完全相同，另一侧有没有观测也会改变误差。** 这些是理想模型中的可复现实证与代数核对，不是一个新算法；新颖性未建立。

## 1. 问题背景：40 个数据点没了，怎么判断补得好不好？

想象一条线上有 200 个等间距的理想传感器，编号 0 到 199。每个传感器报告一个数。相邻位置往往比较相似，隔得很远就不那么相似。我们知道其中 160 个数，想预测其余 40 个。

“缺了 40 个”还没有把任务说清楚。下面三种情况有相同的训练样本数，但可利用的信息不同：

| 缺失方式 | 可以利用什么 | 本单元中的例子 |
|---|---|---|
| 随机散落的缺点 | 绝大多数缺点旁边很快就有观测 | 随机五折，每折隐藏 40 个位置 |
| 连续内部缺口 | 缺口两端都还有观测，中央比较难猜 | 隐藏位置 73 到 112 |
| 连续边缘缺口 | 只有一个方向还有观测 | 隐藏位置 0 到 39 |

传感器只是便于理解的背景。实际计算全部使用自己生成的、无量纲的合成高斯场；没有现实温度、森林、健康、个人或生物实验数据。这样我们既知道“真实数值”，也能算出理想预测器的精确平均误差。

交叉验证的做法是：先隐藏一些已知值，用剩下的值做预测，再揭开答案评分。它的关键不只是“有没有隐藏答案”，还包括**隐藏出来的任务，是否与将来真正要做的任务相似**。这条原则已有明确文献依据，[Roberts 等 2017](https://nsojournals.onlinelibrary.wiley.com/doi/10.1111/ecog.02881) 也明确把预测目标放在划分设计之前。

## 2. 先修逻辑：只先用平均、平方和随机数

你可以从下面四个概念开始，不需要先学微积分。

**平均平方误差 MSE。** 对每个点计算“真实值减预测值”，平方后取平均。例如真实值为 `[1,2]`，预测值为 `[0,4]`，MSE 是 `(1²+(-2)²)/2=2.5`。平方使正负误差不会抵消，也会更重地惩罚大误差。

**方差。** 把同一随机实验独立重复很多次，数值围绕平均值的平方偏离再取平均，就是方差。本实验把每个位置的方差设为 1，便于比较。如果完全无法利用其他信息，只预测已知的平均值 0，平均 MSE 就是 1。

**相关。** 两个位置是否倾向于一起高、一起低。这里距离为 `d` 的两个位置，相关系数设成 `exp(-d/ell)`。`ell` 是相关长度：当距离等于 `ell` 时，相关约为 0.368。`ell=0` 在代码中专门表示彼此独立的对照，并不执行除以零。

**一次独立重复是什么？** 本单元的一次重复是整条 200 点的场。一个场内的点彼此相关，多个验证折也共享同一条场；不能把这些点和折都当作独立重复。8192 条独立场可以提供 8192 次独立的整场误差观测。

读代码时只需先知道：二维数组的每行是一条场，每列是一个位置；`field[:, train]` 是所有场中允许使用的训练列，`field[:, test]` 是留出的答案列。

## 3. 如何造出既随机又可核验的数据

先生成彼此独立、平均值为 0、方差为 1 的正态随机数。令：

`a = exp(-1/ell)`，`s = sqrt(1-a*a)`。

然后按位置递推：

`field[j] = a*field[j-1] + s*new_random_number`。

直觉是：下一点保留上一点的一部分，再加入一部分新变化。保留比例 `a` 越大，相邻点越像。新变化的比例并非随意选择：两个独立部分的方差相加，得到 `a²+s²=1`，所以每个位置始终保持方差 1。相隔两步保留 `a²`，相隔 `d` 步保留 `a^d=exp(-d/ell)`，正好得到我们规定的相关关系。

首点也从同一个标准正态分布抽取，避免起始点方差与其他点不同。完整程序用 `expm1` 稳定计算 `1-exp(-2/ell)`；当两个数非常接近时，这样比先算指数再相减更准确。

这个递推也解释了为何能做独立校验：同一种高斯场可以由“逐点递推”生成，也可以由完整协方差矩阵的 Cholesky 分解直接生成。两种算法不需要产生同一条随机曲线，但它们应该给出相同的平均误差和相关关系。

## 4. 完整最小可运行代码

下面就是文件 `minimal.py` 的全文。只依赖 NumPy，不下载数据，不联网，不调用付费服务。代码首先运行无相关对照，再运行主案例；不是只展示公式的伪代码。

在本目录、已安装 NumPy 的 Python 环境中：

```bash
OPENBLAS_NUM_THREADS=1 python -B -X utf8 minimal.py
```

两份最小代码只需 NumPy。原始完整实验使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、Matplotlib 3.10.8；本版不要求安装绘图库。

```python
"""最小实验：只需 NumPy。手动运行 python minimal.py；不联网，不自动重启。"""
import numpy as np


def run(ell, ell_index):
    n, w, repeats = 200, 40, 8192
    x = np.arange(n)
    K = np.eye(n) if ell == 0 else np.exp(-abs(x[:, None] - x) / ell)
    rng = np.random.default_rng([2026101502, ell_index])
    field = rng.standard_normal((repeats, n))
    if ell > 0:  # 每行是一条独立的场；相邻列彼此相关。
        a, s = np.exp(-1 / ell), np.sqrt(-np.expm1(-2 / ell))
        for j in range(1, n):
            field[:, j] = a * field[:, j - 1] + s * field[:, j]

    def score(test, rows=None):
        train = np.setdiff1d(x, test)
        assert len(train) == 160 and not np.intersect1d(train, test).size
        cross = K[np.ix_(train, test)]
        W = np.linalg.solve(K[np.ix_(train, train)], cross).T
        variance = 1 - np.sum(W * cross.T, axis=1)
        error = field[:, test] - field[:, train] @ W.T
        if rows is not None:  # 未评分的缺失点依然不能放回训练。
            variance, error = variance[rows], error[:, rows]
        return float(variance.mean()), (error ** 2).mean(axis=1)

    blocks = [score(np.arange(j * w, (j + 1) * w)) for j in range(5)]
    random_scores = []
    for p in range(20):
        order = np.random.default_rng(2026101501 + p).permutation(n)
        random_scores += [score(np.sort(test)) for test in np.split(order, 5)]
    groups = {"random_cv": random_scores, "blocked_cv": blocks,
              "interior_cv": blocks[1:4], "edge_cv": [blocks[0], blocks[4]]}
    print(f"ell={ell}; 误差条针对仿真均值，不是单次预测")
    exact = {}
    for name, scores in groups.items():
        truth = float(np.mean([s[0] for s in scores]))
        loss = np.mean([s[1] for s in scores], axis=0)
        se = loss.std(ddof=1) / np.sqrt(repeats)  # 独立单位是整行。
        exact[name] = truth
        print(f"{name:12s} exact={truth:.8f} MC={loss.mean():.8f} +/- {1.96*se:.8f}")
    assert np.isclose(exact["blocked_cv"],
                      .6 * exact["interior_cv"] + .4 * exact["edge_cv"])
    if ell == 0:
        assert all(np.isclose(v, 1) for v in exact.values())
    else:  # 不使用矩阵求解的两端公式，再检查一次。
        d = np.arange(1, w + 1)
        bridge = ((-np.expm1(-2*d/ell)) * (-np.expm1(-2*(w+1-d)/ell))
                  / (-np.expm1(-2*(w+1)/ell)))
        assert np.isclose(bridge.mean(), exact["interior_cv"])
    inside = score(np.arange(73, 113), np.arange(20))[0]
    edge = score(np.arange(40), np.arange(20, 40))[0]
    print(f"同为最近距离1..20：内部={inside:.8f} 边缘={edge:.8f}")


if __name__ == "__main__":
    run(0.0, 0)   # 无相关负对照
    run(40.0, 4)  # 主案例；索引4与完整方案一致
```

几个值得逐步看的地方：

1. `score` 永远先排除全部 40 个缺失点，再从训练值计算预测。即使只评分其中 20 点，另外 20 个缺失值也没有被放回训练。
2. `np.linalg.solve` 是解方程，而不是手动求矩阵的逆。暂时可以把它当成“找到一组合适的训练点权重”；后面解释这些权重来自哪里。
3. 随机五折有 20 个固定划分，不挑选有利的种子。每个划分都覆盖全部位置一次；最终对全部 100 个折的平方误差取平均。
4. 标准误是先在每条场内合并所有相关的评分，再在独立场之间计算。代码中的 `+/-` 是仿真均值的近似 95% 区间半宽。
5. 最后两个调用从主案例中取出相同的最近距离分布，用于检查单端和双端观测的区别。独立种子、独立采样器的探索性实验结果在 `evidence/mechanism_summary.json` 中；最小代码只复现其精确风险，不复现该探索性实验的独立 Monte Carlo 样本。

实际最小代码输出的主案例为：

```text
random_cv    exact=0.02937342 MC=0.02940124 +/- 0.00007144
blocked_cv   exact=0.42796960 MC=0.42817907 +/- 0.00411167
interior_cv  exact=0.32769208 MC=0.32689755 +/- 0.00355608
edge_cv      exact=0.57838589 MC=0.58010136 +/- 0.00881983
```

## 6. 不用微积分也能核验的端点公式

下面的 `E` 可以先理解为“无限次独立重复的平均”。我们已经规定平均值为 0，方差为 1。

### 只有一个有用的观测端点

设缺失值为 `Y`，最近观测值为 `X`，二者相关为 `u=exp(-d/ell)`。如果用 `c*X` 预测 `Y`，展开平方得到：

`E[(Y-cX)²] = 1-2cu+c² = (c-u)² + 1-u²`。

这已经配成一个平方项加常数。显然 `c=u` 时最小，精确 MSE 是：

`V_edge(d) = 1-exp(-2d/ell)`。

本模型中，更远的同侧观测不会在已知最近端点后继续增加信息。这是递推高斯场的 Markov 性质，不能推广为“现实问题只需要最近邻”。

### 两边都有观测端点

设左右端点为 `L,R`，距缺失点分别为 `d_left,d_right`。记：

`u=exp(-d_left/ell)`，`v=exp(-d_right/ell)`。

两端之间的相关为 `u*v`。预测写成 `p*L+q*R`；让预测残差与两个端点都不相关，会得到两个线性方程：

```text
p + (u*v)*q = u
(u*v)*p + q = v
```

解得：

```text
p = u*(1-v*v)/(1-u*u*v*v)
q = v*(1-u*u)/(1-u*u*v*v)
V_inside = (1-u*u)*(1-v*v)/(1-u*u*v*v)
```

正态联合分布使这里的最佳线性预测也等于条件平均值。它不是随意的线性插值；端点权重不必加起来等于 1，因为模型已经知道总体平均值是 0。若改成未知平均值，算法与结论都要重新检查。

缺了连续 40 点时，两个外侧端点相距 **41** 个网格间隔，不是 40。对 `d=1,…,40` 把 `d_left=d`、`d_right=41-d` 代进去，再取平均，就得到 0.3276920824。边缘情况只有 `d=1,…,40` 的单端公式，得到 0.5783858851。

五个连续块中有三个内部块、两个边缘块，且每块评分点数相同，所以一定有：

`完整分块风险 = 0.6*内部风险 + 0.4*边缘风险`。

因此混合方案回答的是“60% 内部、40% 边缘”的任务，不会自动等于纯内部部署风险。这个等式在每条场的实际误差上也成立；保存的数据已逐条检查。

**可选的长相关极限。** 当 `ell` 远大于缺口宽度 `w`，用 `1-exp(-x)` 接近 `x`，单端平均风险接近 `(w+1)/ell`，双端接近 `(w+2)/(3*ell)`。本实验 `w=40`，完整分块/内部风险比趋于 `0.6+0.4*3*41/42=1.77142857`。独立稳定公式在 `ell=1e8` 给出 1.77142826。这个极限是模型的标准代数推论，不是新颖性声明；它解释了为何边缘混合的相对影响在强相关时仍不消失。

## 7. 探索性机制检验：最近距离配平以后，还差什么？

这个问题在主实验之后提出，另行固定方案，随后计算。原主方案与主数据没有被改写。它属于同一个研究单元中的**探索性延伸**。

仍缺 40 个点、训练 160 个点，但每个情景只评分 20 点：

- 内部：隐藏 `[73:113]`，评分 `[73:93]`。最近观测在 72，距离是 1 到 20；另一侧 113 也有观测。
- 边缘：隐藏 `[0:40]`，评分 `[20:40]`。最近观测在 40，距离是 20 到 1；另一侧没有观测。

两边评分点数相同，最近距离的整个分布相同，训练点数相同。主案例的精确风险仍分别为 **0.327692** 与 **0.383551**，边缘高出 **17.05%**。新的 8192 条配对场得到差值 0.058174，95% 仿真区间 `[0.046966,0.069381]`；精确差值为 0.055859，落在该区间内。

弱相关时这个额外信息可能几乎没用：`ell=2` 的精确差约 `6e-11`，远小于本次仿真的分辨能力；`ell=0.5` 的理论差甚至小到无法由本次双精度风险相减可靠分辨。不能把主案例的清楚效果说成每个相关长度下都能用这批 Monte Carlo 检出。

对相同最近端距离，单端方差减去双端方差可以直接化成：

`V_edge - V_inside = v²*(1-u²)²/(1-u²*v²)`。

只要两个相关都严格介于 0 和 1，它就是正数。最近距离告诉我们 `u`，却没有告诉我们另一侧的 `v`。这已经足以构造一个“最近距离分布相同，但误差不同”的模型反例，不需要猜测真实地图的行为。

本单元**没有运行 NNDM 或 kNNDM 软件**，因此不能把这个结果当成对其实际算法的性能评测。距离匹配早有 [Milà 等 2022](https://besjournals.onlinelibrary.wiley.com/doi/10.1111/2041-210X.13851) 和 [Linnenbrink 等 2024](https://gmd.copernicus.org/articles/17/5897/2024/)；这里仅检查把一个距离摘要当作完整任务描述时的逻辑边界。2026 年 [Brenning 与 Suesse 的目标加权验证预印本](https://arxiv.org/html/2603.29981v1) 也讨论了部署任务的描述与匹配；尚未同行评审，不应把本单元说成先于该研究方向。

## 8. 独立校验、负对照和实际失败记录

完整校验器不导入主实验函数。它用两种不同计算路线对照保存的密集 GP 权重：

1. 上面逐点的单端/双端条件公式。
2. 从 AR(1) 递推直接构造三对角精度矩阵，再解缺失点的条件系统。这里先解 40 点的系统，主算法先解 160 点的训练协方差系统。

六个相关长度、每个 107 个划分，共检查 **642 组**，涉及 **4,108,800 个权重系数**。最大权重差 `2.89e-13`，最大条件方差差约 `1.52e-14`，精确风险差不超过 `4.45e-16`，都低于预定 `1e-9` 容差。额外的直接 Cholesky 采样给内部部署 MC=0.325685、边缘部署 MC=0.578454，均与各自精确风险相符。

无相关负对照的所有精确风险均为 1。随机和分块在同一 iid 场上的评分最大差 `1.11e-15`。另外，把留出答案大幅改动后，基于训练值的预测变化为 0；保存的所有训练/测试集合无交集。这些检查各自针对一个可能错误，比只重复运行同一段代码更有用。

**实际保留的不顺利结果也要读：**

- 主实验 36 个名义 95% 区间有 1 个没有覆盖精确值：iid 边缘部署，偏离 2.127 个标准误。
- 探索性 iid 配对差的精确值是 0，但一次仿真的 95% 区间为 `[0.001465,0.020868]`，偏离 2.256 个标准误。这是原样保留的假阳性实例，没有被写成真实机制效应，也没有换种子重跑。
- 两个情况都低于事先规定的 5 标准误实现警戒线。该警戒线是发现程序/生成器异常的粗检查，不是“95% 区间永远可靠”的保证。真正保留的机制结论来自能逐项核验的精确风险。

在主案例的内部部署中，若把同场 40 个误差当作独立点，会使仿真均值标准误低估约 **3.61 倍**。本单元报告的标准误始终在独立完整场之间计算。区间描述的是“8192 次仿真得到的平均风险有多精确”，不描述“下一次单独部署一定落在哪个区间”。

独立算法由同一研究者实现；这不等于独立人类审稿。数据、代码和数学相互核对可以提高可信度，不能代替同行审查或现实外部验证。

## 9. 矩阵算法的技术细节与原始参考

如果想继续阅读完整程序，先记住形状即可：训练协方差为 `160×160`，训练与缺失点的协方差为 `160×40`。求出的权重 `W` 为 `40×160`。8192 条训练数据形成 `8192×160` 数组，乘 `W.T` 后得到 `8192×40` 个预测。

下面按批量代码中“每行一条场”的存储方式写出标准计算：

```python
Krr = K[np.ix_(train, train)]   # 160×160
Krt = K[np.ix_(train, test)]    # 160×40
Ktt = K[np.ix_(test, test)]     # 40×40
W = np.linalg.solve(Krr, Krt).T
prediction = field[:, train] @ W.T
S = Ktt - W @ Krt
exact_MSE = np.diag(S).mean()
```

`np.ix_` 帮助按行索引和列索引选出一个完整子矩阵。`@` 是矩阵相乘；此处不显式构造逆矩阵。完整实现用 Cholesky。`S` 是整个误差向量的协方差，其对角线是每个点的平均平方误差。

算法原始教材依据为 [Rasmussen 与 Williams 2006，第 2 章，式 2.23–2.24 和算法 2.1](https://gaussianprocess.org/gpml/chapters/RW2.pdf)。本单元独立端点推导只用了上述模型的二变量代数，不要求先理解完整高斯过程教材。

验证原则的补充原始来源：[Rabinowicz 与 Rosset，JASA 2022，作者预印本 v3](https://arxiv.org/html/1904.02438v3) 分析了相关数据下验证和目标分布的关系；[Ploton 等 2020](https://www.nature.com/articles/s41467-020-18321-y) 给出生态空间映射中的实证例子。本单元没有重跑那些论文的数据和数值，不能称作其逐项复现。

此次研究的证据类别为：

| 类别 | 本单元能支持的说法 |
|---|---|
| 已有方法 | 高斯条件预测、AR(1)、Cholesky、按预测目标设计验证 |

## 13. 什么叫计算路线独立？

重新调用同一个函数，往往只会重复同一种错误。这次没有导入原实验函数，使用了不同的表示方式。

把一条场写成`f=Tz`：`z`是一袋互不相关、方差为1的随机原料，`T`告诉我们每个位置混入了哪些原料。第一个位置是`z[0]`；第二个是`a*z[0]+s*z[1]`；第三个是`a*a*z[0]+a*s*z[1]+s*z[2]`。这只是第一部分递推公式展开后的样子。

若预测器使用权重W，误差可以写为`D z`，其中`D=T_score-W@T_train`。一行D里的系数乘在独立、方差为1的原料上，因此该点误差的方差就是这些系数的平方和。再对评分点平均，就得到真实MSE。这里无需先使用原程序的“后验协方差”公式。

此外，QR分解把训练信息所占的方向写成相互垂直的方向。把目标投影到这些方向上，相当于在训练能表达的部分里找最佳预测。你可以先把它想成：用若干条互不重复的方向，拼出尽可能接近目标的影子。独立求得权重后，再比较原程序保存的权重。

实际核查了642个长度/划分组合、4,108,800个权重系数。新风险与原结果的最大差为`4.44e-16`，新权重与原权重的最大差为`2.87e-13`，小于冻结阈值`1e-9`。这些差属于本次浮点误差量级；没有因此把容差放宽。

这叫算法路线独立，不等于外部同行盲审。研究者已经看到旧结果，能够有针对性地检查，也可能共享概念盲点。文件明确保留这一限制。

## 14. 为什么多做20个随机划分，不等于多得到20倍独立数据？

同一条200点曲线反复分成不同折，原始数值并没有变多。特别是在iid负对照中，预测都为0；每个平衡五折最后都把同样200个平方值平均一次。重复20种划分，整个平均值仍是那个平均值。

如果错误地把100个折当成独立实验，iid对照的标准误会被缩小`√20≈4.47`倍。在真实主案例长度40中，本次独立计算给出的倍率是4.3957446。原程序没有犯这个错误：先算每条完整场的平均损失，再用8192条场之间的波动计算标准误。

可选技术解释：标准正态向量z的二次型损失写成`z.T @ G @ z`。若G是对称矩阵，均值为`trace(G)`，方差为`2*sum(G*G)`。共享同一z的多个折，必须先平均G再算方差。先分别算方差再当独立相加，会漏掉折之间的协方差。该推导是高斯二次型的标准性质，本次只是把它用于明确检验。

旧教程中的3.61倍是另一件事：把一个缺口内40个相关误差当独立点。不能把3.61与4.40当成同一量的两个估计。

原来两次95%区间没有覆盖精确值，也都保留了。95%是重复抽样的长期性质，不是每次区间都必含真值；更不能看到一次未覆盖就删除样本或重新选种子。主结果由精确计算和不同算法支撑，Monte Carlo是核查手段。

## 15. 新问题：模型相信的距离，可能不是真实的距离

第一部分的预测器有一个现实中很强的优势：知道真实相关长度。现在把这两个量分开：

- `true_length`：生成世界时使用的真实相关长度；在合成实验中我们知道它。
- `model_length`：预测器相信的相关长度；故意允许它与真值不同。

例如真实长度为2、假定为10，意味着世界变化得较快，预测器却相信较远的邻居仍很相关。它可能过多使用远处观测。这里参数由实验者固定，没有用数据拟合，不能把结果说成某种参数估计器必然失败。

文献先于这次新增计算查阅。协方差误设及真实MSE与报告方差的区别已见[Bachoc2013，第2节](https://arxiv.org/html/1301.4320v2)；训练配置信息不止最近距离也见[kNNDM2024的限制讨论](https://gmd.copernicus.org/articles/17/5897/2024/)。本单元不提出新算法，也未建立新颖性。它提供一组容易复算的有限几何边界。

新增方案在运行前固定。真实长度取9值`[0,0.5,2,5,10,20,40,80,200]`，假定长度取5值`[0,2,10,40,200]`，共45组全部保留。`0`仍专指iid。

## 16. 把平方乘开，就能区分真实风险与模型自报方差

评分点离左端点d步，离右端点`41-d`步，`d=1,…,20`。记模型认为的相关为A、B：

```text
A = exp(-d/model_length)
B = exp(-(41-d)/model_length)
p = A*(1-B²)/(1-A²B²)
q = B*(1-A²)/(1-A²B²)
```

单端预测是`A*L`，两端预测是`p*L+q*R`。接下来千万不要把A、B直接当真实相关。用u、v、r表示真实的`Y与L`、`Y与R`、`L与R`相关：

```text
u = exp(-d/true_length)
v = exp(-(41-d)/true_length)
r = exp(-41/true_length)
```

把`(Y-A*L)²`和`(Y-p*L-q*R)²`乘开，并利用每个变量均值0、方差1，就有：

```text
真实单端MSE = 1 + A² - 2*A*u
真实两端MSE = 1 + p² + q² + 2*p*q*r - 2*p*u - 2*q*v
```

这两行只需要普通乘法和平均的线性性质。模型报告的方差相当于把世界也当成自己的假定，即把真实长度替换为假定长度。只有模型正确，才可以这样代替真实MSE。

这里的真实MSE对训练值和目标值一起重复生成后取平均，是整体风险。误设模型在某一次固定训练观测后的条件MSE还会随训练值变化；不要把它与本表的整体风险混淆。

单端公式还能配方：

`真实单端MSE = 1-u² + (A-u)²`。

前半是知道真实相关时能达到的最小风险，后半是权重设错的额外损失。多变量也有同类分解；完整代码检验了错误权重风险等于最优风险加非负额外损失。

“正确使用更多信息不会更差”仍然成立：有右端点时，总能选择不用它。这里比较的是两个固定错误模型给出的具体权重，错误模型未必会选择那个较好的方案。

```python
import numpy as np


def point_risks(true_length, model_length):
    d = np.arange(1, 21, dtype=float)

    def correlation(distance, length):
        return np.zeros_like(distance) if length == 0 else np.exp(-distance / length)

    # A、B是模型相信的相关；u、v、r是真实相关。
    A = correlation(d, model_length)
    B = correlation(41 - d, model_length)
    denominator = 1 - A*A*B*B
    p = A * (1 - B*B) / denominator
    q = B * (1 - A*A) / denominator
    u = correlation(d, true_length)
    v = correlation(41 - d, true_length)
    r = correlation(np.full_like(d, 41), true_length)
    one = 1 + A*A - 2*A*u
    both = 1 + p*p + q*q + 2*p*q*r - 2*p*u - 2*q*v
    return one, both, A, p, q


def simulate(true_length, model_length, case_index):
    one, both, A, p, q = point_risks(true_length, model_length)
    reported_one, reported_both, *_ = point_risks(model_length, model_length)
    x = np.arange(42)
    K = (np.eye(42) if true_length == 0 else
         np.exp(-abs(x[:, None] - x[None, :]) / true_length))
    rng = np.random.default_rng([2026101507, case_index])
    fields = rng.standard_normal((2048, 42)) @ np.linalg.cholesky(K).T
    # 同一组目标和左端点，比较两种预测，降低差值的随机噪声。
    target = fields[:, 1:21]
    pred_one = fields[:, [0]] * A
    pred_both = fields[:, [0]] * p + fields[:, [41]] * q
    loss_one = ((target - pred_one)**2).mean(axis=1)
    loss_both = ((target - pred_both)**2).mean(axis=1)
    difference = loss_one - loss_both  # 每行是一条独立场的配对差。
    se = difference.std(ddof=1) / np.sqrt(len(difference))
    print(f"真实长度={true_length}, 假定长度={model_length}")
    print(f"  真实MSE: 单端={one.mean():.9f}, 两端={both.mean():.9f}")
    print(f"  报告方差: 单端={reported_one.mean():.9f}, 两端={reported_both.mean():.9f}")
    print(f"  单端减两端: 精确={(one-both).mean():.9f}, "
          f"MC={difference.mean():.9f}, 95%区间="
          f"[{difference.mean()-1.96*se:.9f}, {difference.mean()+1.96*se:.9f}]")
    if true_length == model_length == 0:
        assert np.all(difference == 0)


if __name__ == "__main__":
    for index, (truth, model) in enumerate([(0, 10), (2, 10), (40, 40), (0, 0)]):
        simulate(truth, model, index)
    # 一次括区二分，只报告一个过零点，不证明唯一性。
    lo, hi = .5, 20.0
    for _ in range(50):
        mid = (lo + hi) / 2
        one, both, *_ = point_risks(mid, 10)
        if (one - both).mean() < 0:
            lo = mid
        else:
            hi = mid
    print(f"假定长度10时，本括区过零点约为{(lo+hi)/2:.9f}")
```

## 19. 为什么小实验可以只生成42点？共同随机数是什么意思？

原任务仍是训练160点、缺失40点、评分20点。指数模型具有Markov性质，实际预测权重只落在最近端点；其他同侧观测的权重为0。平稳性和左右反射对称性允许把两种评分误差分别平移到`1,…,20`，最近端点设为0，另一个端点设为41。因此计算每个任务的边缘风险只需要这42点的联合分布。

本次模拟让两种预测使用同一组目标值与左端点。这样两种误差会一起涨落，做差时抵消一部分共同噪声，称为共同随机数。它保留两种任务各自的平均风险，却改变它们之间如何配对；不能把本次差值标准误当成第一部分同一200点曲线上的配对标准误。

形式上，只要A和B各自分布保持原样，`平均(A-B)=平均A-平均B`；A与B是否独立不影响这个等式，但会影响差值的方差。所以必须保存配对差，并从2048条独立小场的差值之间算标准误。

对`真实0、假定0`，两种预测都为0，共用目标使每条差值严格等于0。实际2048条差值全部为0，这是一个强的恒等式负对照。真实0、假定10是另一回事：模型错误借用了本不相关的邻居，所以真实MSE大于1并不违背负对照逻辑。

## 21. 练习与可复用路径

1. **先手算平方。** 从`(Y-pL-qR)²`出发写出6项，逐项解释为何出现`2*p*q*r`。参考：交叉项`2pqLR`的平均是`2pqr`；两个与Y的交叉项都带负号。
2. **辨认分母。** 用表中的1.103229422与1.100060333，分别计算“单端相对两端”和“两端相对单端”的百分比。两者绝对值不会完全相同，因为分母不同。
3. **做正确模型对照。** 调用`point_risks(10,10)`，比较报告方差与真实MSE。再调`point_risks(2,10)`，注意只改变真值不会改变模型权重p、q。
4. **拆开误设代价。** 单端逐点检验`one == 1-u*u+(A-u)**2`。解释为何真相关u很小而假定A较大时，预测会比恒预测0更差。
5. **理解耦合。** 先阅读每条差值，再考虑把单端预测换用另一条独立场会发生什么。期望差仍相同，但标准误一般不同；不要把两种配对的标准误混用。若未来实际实施，先另定样本量与种子，不修改本次结果。
6. **检查过零点。** 不需新抽样，只计算真实长度7.65和7.66时的解析差。它说明局部异号；要证明唯一根，还需要关于差值函数的数学论证。
7. **规划下一研究。** 若将来加入观测噪声，先决定要预测潜在场还是带噪声的新观测；若要估计长度，先决定参数在每折内怎样估计以及部署时怎样估计。没有这些定义，不能把新的数字与本表直接比较。这些是未来可做的问题，不是本次已完成的结论。

建议阅读顺序是：先学MSE与独立重复，运行第一份代码；再看三个除法和统计相关性；接着只靠平方展开理解误设，运行第二份代码；最后按需要看矩阵/QR、源码和原文。每一步都有可检查输出，不把任何内容标记为你已经掌握。
