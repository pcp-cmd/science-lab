## 运行

- E01：`python minimal_example.py`，需要 NumPy、SciPy，给出矩阵指数的浮点近似。

E01 主例随机环境和平均环境的灭绝概率约为 0.433281434244 和 0.215104042216。
E02 给出根区间 [6.8707275390625, 6.871337890625]。最小程序证明存在，不证明唯一；教程另述局部唯一性的推导，独立复核程序未收入。
