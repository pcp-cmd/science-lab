# 平均天气为什么不等于平均命运：一个可运行、可检查的随机种群实验

## 1. 我们究竟问什么

设一个小种群从8个个体开始。环境有好、坏两种，好时每个个体的死亡速率为0.5，坏时为1.5。它们长期各占一半，所以平均死亡速率是1。将环境一直设为中等、死亡速率固定为1，能否准确算出十单位时间内种群灭绝的概率？

本轮给定模型的答案是：随机环境约43.33%，平均环境约21.51%。差21.82**个百分点**；前者约为后者2.014倍。它是理想化模型的计算实验结果。没有某种真实动物的观测数据，也没有把时间单位换算成实际年份。

科学意义在于检查一个常见近似的适用范围：平均参数方便，但系统的命运可能取决于坏环境持续多久、种群当时多小，以及零是否不可恢复。环境噪声与灭绝是成熟研究主题：[Spalding等2017](https://arxiv.org/abs/1710.06274) 已研究双环境死亡率。本轮提供一个明确的有限模型、可复算的误差和可审查的包围区间，尚不构成新生态机制或经专家认可的新发现。

## 2. 直觉与一个会纠正直觉的反例

种群在坏环境里变小后，同一段坏天气更可能把最后几个个体带走。到零就不能自行生出后代；以后天气转好也无济于事。因此“先平均天气再算命运”可能改变结果。

但不能据此断言平均环境总低估灭绝。只有一个个体、没有出生时，初始一半好、一半坏且不切换，时间1内幸存概率为

\[
S_{\rm random}(1)=\tfrac12e^{-1/2}+\tfrac12e^{-3/2},\qquad
S_{\rm average}(1)=e^{-1}.
\]

第一项约0.41483，比第二项约0.36788大；所以随机环境的灭绝概率约0.58517，反而比对照0.63212小。这里好环境中的长期幸存者提高了平均幸存率。

更一般地，在N=1的无出生模型中，给定一条环境轨迹，幸存概率为 `exp(-累计死亡危险)`。指数函数的凸性意味着“先算指数再平均”至少等于“先平均危险再算指数”。这就是Jensen不等式的一次标准应用，不是本轮新发现。它也适用于正切换率；ν=.1、时间1时随机灭绝概率约0.58816，方向仍反向。出生和密度反馈加入后，不能直接把这个简式搬到主模型。

严谨地，设随机累计死亡危险为Z，初始环境为平稳分布时E[Z]=t。利用 `e^w≥1+w`，对任意z有 `e^{-z}≥e^{-t}(1-(z-t))`。两边取期望，右边成为e^{-t}，便证明随机幸存概率至少为平均模型的幸存概率。这不需要猜测误差方向；它只适用已给出的无出生死亡模型。

## 4. 模型：每个符号都对应一个可描述的事件

种群数n是整数0到N，本轮N=16。N是模型本身的硬上限，并不是将无限种群模型偷偷截断。0是吸收态：到零以后没有出生或移入。

出生总速率为

\[
b_n=2n(1-n/N).
\]

一种微观解释是：每个个体以速率2尝试生育，成功比例为 `1-n/N`。所以n=8时b=8，n=16时b=0。死亡总速率是 `d_n=μ_e n`，μ_e在0.5和1.5中切换。环境是整个种群共享的一个状态，不是每个个体分别抽一次天气。

速率ν=.1表示环境在每个方向的切换速率；一次环境状态的平均持续时间为1/ν=10，相关时间为1/(2ν)=5。初始好、坏环境各概率1/2，与初始种群n=8一起冻结。平均模型采用μ̄=(0.5+1.5)/2=1，保持相同出生规则和n=8。

**速率不是一步的概率。** 速率8表示当前状态下的瞬时发生强度，它可以大于1。在很短时间h内，该事件概率约为8h，忽略误差相对h趋零的更小项。如果速率一直保持8，单位时间内的平均次数才是8；本模型状态会变化，不能把当前速率直接乘整段时间当作期望事件数。模拟也不能把8当作掷硬币概率。

在状态(n,e)，三种事件的速率和为R=b_n+d_n+ν。下一事件等待时间W满足

\[
\Pr(W>w)=e^{-Rw}.
\]

这是指数等待时间，均值1/R。等到事件发生，再按b_n/R、d_n/R、ν/R选择出生、死亡或环境切换。这就是Gillespie模拟。好环境n=8时R=12.1；坏环境R=20.1。环境自身不需要记忆已持续多久，是因为指数等待具有无记忆性；如果天气持续时间不是指数分布，必须换模型。

## 5. 完整最小代码与运行步骤

```bash

```

本目录提供同内容文件 `minimal_example.py`。原教程记录的输出如下；矩阵指数给浮点近似，严格证书在第8节。

```text
随机环境灭绝概率：0.433281434244
平均环境灭绝概率：0.215104042216
差：0.218177392028
```

```python
"""自包含最小例子。运行：python -B minimal_example.py
需要已安装的 NumPy、SciPy；矩阵指数计算是浮点近似。
"""
import numpy as np
from scipy.linalg import expm


def extinction_probability(N, n0, nu, time, averaged=False):
    if N < 1 or not 0 <= n0 <= N or nu < 0 or time < 0:
        raise ValueError("参数超出模型范围")
    environments = [0] if averaged else [0, 1]
    states = [(n, e) for n in range(1, N + 1) for e in environments]
    index = {state: i for i, state in enumerate(states)}
    dead = len(states)
    G = np.zeros((dead + 1, dead + 1))
    for (n, e), i in index.items():
        birth = 2 * n * (1 - n / N)
        mortality = 1 if averaged else [0.5, 1.5][e]
        if n < N:
            G[i, index[n + 1, e]] += birth
        target = dead if n == 1 else index[n - 1, e]
        G[i, target] += mortality * n
        if not averaged:
            G[i, index[n, 1 - e]] += nu
        G[i, i] = -G[i].sum()
    # 最后一行全零：灭绝后保持灭绝。
    assert np.max(np.abs(G.sum(axis=1))) < 1e-12
    initial = np.zeros(dead + 1)
    if n0 == 0:
        initial[dead] = 1
    else:
        for e in environments:
            initial[index[n0, e]] = 1 / len(environments)
    final = initial @ expm(time * G)
    assert abs(final.sum() - 1) < 1e-12
    return float(final[dead])


if __name__ == "__main__":
    switching = extinction_probability(16, 8, 0.1, 10)
    average = extinction_probability(16, 8, 0.1, 10, averaged=True)
    print(f"随机环境灭绝概率：{switching:.12f}")
    print(f"平均环境灭绝概率：{average:.12f}")
    print(f"差：{switching - average:.12f}")
    assert abs(switching - 0.4332814342438991) < 1e-11
    assert abs(average - 0.2151040422159595) < 1e-11
    assert extinction_probability(16, 0, 0.1, 10) == 1
    assert extinction_probability(16, 8, 0.1, 0) == 0
```

先找 `states`：它列出“种群数、环境”二元组。`index`把每个二元组映射到矩阵的行号。最后一行号 `dead`表示已经灭绝。每个非对角矩阵格存向某状态跳转的速率；对角格是本行总离开速率的负值。行和为零对应概率质量守恒。

`initial`是初始概率向量。`expm(time*G)`让整个概率分布演化到截止时间。`initial @ ...`中的 `@`是矩阵乘法；最终吸收态格子的概率就是灭绝概率。修改N时，请同步决定n0；修改ν时，不要误改死亡率。

## 6. 从直觉到矩阵公式：保留严谨解释

用行向量p(t)记录每个状态的概率。生成元G的非对角条目G_ij表示从i到j的速率，对角条目为负的离开速率。G每行和为零，吸收态一行全零。

短时间h内，转移矩阵为 `I+hG+o(h)`，I是保持原状态的单位矩阵。把时间切成许多小段并取极限，得到

\[
p'(t)=p(t)G,\qquad p(t)=p(0)e^{tG}.
\]

导数p′表示概率变化有多快。矩阵指数定义为 `e^{tG}=Σ_{k≥0}(tG)^k/k!`；这不是将每个格子分别取指数。科学代码的A路径也可删去吸收态，仅用瞬态Q：

\[
\Pr(T\le t)=1-p(0)e^{tQ}\mathbf1.
\]

其中1是全1列向量，最后的乘法把所有尚未灭绝状态概率相加。Q的行和允许小于零；n=1的死亡概率流向被省略的吸收态。仅对Q要求行和零会把灭绝泄漏删掉。

另一条独立检查用后向方程。u_e,n(t)表示从指定(n,e)出发、t以内灭绝的概率，满足

\[
\partial_tu_{e,n}=b_n(u_{e,n+1}-u_{e,n})+
\mu_en(u_{e,n-1}-u_{e,n})+
\nu(u_{1-e,n}-u_{e,n}).
\]

边界u_e,0(t)=1，初始u_e,n(0)=0（n>0）；n=N处出生项不出现。主答案是两种环境的u_e,8(10)各取一半。新写的这条方程没有调用A/B的生成矩阵，主点与A差约10⁻¹⁴。

平均模型使用平均**速率**。它不同于对两个固定环境下的灭绝概率求平均，也不同于对每条随机天气轨迹求概率后平均。在ν=0时，后一过程恰是两个固定环境结果的等权混合；ν>0时还要计入切换历史。

## 8. 为什么整数证书确实包住答案

这里给出完整逻辑，不要求你先有高数背景；P6–P7可据此补学。选择整数λ至少等于所有状态的最大离开速率，令

\[
P=I+G/\lambda,\qquad x=\lambda t.
\]

P是普通一步概率矩阵：元素非负，每行和1。它额外允许“发生一次记号事件但状态不变”，填平不同状态的总时钟速率。有限矩阵恒等式G=λ(P−I)给

\[
e^{tG}=e^{-x}\sum_{k=0}^\infty\frac{x^k}{k!}P^k.
\]

这就是均匀化：总记号事件数具有Poisson权重，条件于发生k次后用P走k步。[Gross与Miller1984](https://doi.org/10.1287/opre.32.2.343) 是这一成熟随机化计算方法的既有文献。本轮使用其标准有限状态表示，自行写出整数实现和下列尾界。

令p_k是k步后在吸收态的概率，0≤p_k≤1；a_k=x^k/k!。真实答案是 `e^{-x}Σa_kp_k`。只算0至K项，记

\[
S_K=\sum_{k=0}^Ka_k,\qquad A_K=\sum_{k=0}^Ka_kp_k.
\]

从第K+1项以后，相邻指数级数项的比例最多ρ=x/(K+2)。当ρ<1时，后面所有项被一个几何级数控制：

\[
0\le e^x-S_K\le B_K:=\frac{a_{K+1}}{1-x/(K+2)}.
\]

分子里每个p_k也至多1，所以它的遗漏尾同样在[0,B_K]。分子至少A_K、至多A_K+B_K；分母至少S_K、至多S_K+B_K。因此

\[
\boxed{\frac{A_K}{S_K+B_K}\le\Pr(T\le t)\le
\min\left(1,\frac{A_K+B_K}{S_K}\right).}
\]

这一步同时处理概率级数截断和指数常数，而非拿未经保证的浮点exp当成精确值。K+2≤x时代码直接拒绝；不会静默输出“精确答案”。

所有本轮速率是有理数。取分母公倍数D，把P的每条事件权重写成整数 `rate*D`，再补足到L=λD的自停留权重。初态有m种等权环境时，k步整数计数对应分母mL^k。代码逐步检查整数计数总和恰为mL^k。计算A_K时，系数化简为

\[
\frac{(\lambda t)^k}{k!}\frac{1}{m(\lambda D)^k}
=\frac{t^k}{mD^k k!}.
\]

Python的整数不会像固定宽度整数那样溢出；`fractions.Fraction`保存完整分子和分母。ν必须写成 `Fraction(1,10)` 或 `'1/10'`；`Fraction(0.1)`保存的是浮点0.1的精确二进制近似。

主随机模型λ=25、x=250，对照λ=18、x=180，K=1000。输出很窄的严格区间，向外舍入到12位即可安全报告：

\[
0.433281434243\le P_{\rm random}\le0.433281434244,
\quad
0.215104042215\le P_{\rm average}\le0.215104042216.
\]

原研究程序保存了比这更窄的精确端点，但该程序及原端点日志未收入此目录。极小区间宽度不等于外部独立验证了几百位，也不把真实概率变成有理数。证书条件是模型确如定义、实现和精确运算正确；本轮完成代码辅助审查，尚无机器形式化或生态专家认证。

## 1. 问题与价值：期限也是模型结论的一部分

保持容量N=8、初始人数4、出生率2n(1−n/8)、好坏死亡系数1/2和3/2、两向环境切换率1/10、初始环境各一半。对照保持相同出生与初态，死亡系数固定1。定义

\[
F_s(t)=\Pr_s(T_{ext}\le t),\quad F_a(t)=\Pr_a(T_{ext}\le t),
\qquad\Delta(t)=F_s(t)-F_a(t).
\]

F是“在截止t以前已经灭绝的概率”，也叫累积分布函数（CDF）。t越晚，包含的灭绝轨迹越多，所以每条F都不下降。但是两条上升曲线的距离可以先增加再减少、甚至改变正负：Δ不是CDF。

本轮严格认证一个非零根位于

\[
[56285/8192,\ 28145/4096]
=[6.8707275390625,\ 6.871337890625],
\]

宽度5/8192≈0.00061035。左端Δ严格为正，右端严格为负。该小区间内导数也严格为负，所以区间内恰有一个根。没有证明它是所有t>0中的第一个根或唯一根。

价值限于：同一模型、同一初态，改变观察截止就能反转平均率近似的误差方向。它给E01的浮点现象增加可审查端点和控制，不是新生态机制，不是现实物种预测。灭绝时间分布和初态早有研究，例如[Kessler与Shnerb2023](https://arxiv.org/abs/2307.08435)；[Spalding等2017](https://arxiv.org/abs/1710.06274)已研究双环境平均灭绝时间。本题由看过的E01输出提出，不能冒充未看数据的全新假设。

## 3. 为什么端点异号能证明根存在

连续性直觉是函数值不会突然从正数跳到负数而完全避开零。精确陈述：若实函数在闭区间[a,b]连续，f(a)>0且f(b)<0，则存在c∈(a,b)，使f(c)=0。这叫介值定理。

本模型状态有限，F(t)=p(0)exp(tG)f，其中f是吸收态的指示列向量。矩阵指数由处处收敛的幂级数定义，每个分量都是解析函数，所以F及两者之差Δ连续。这给出了定理的前提，不是“图画得光滑所以连续”。

本轮向外舍入的端点包围为：

|时间|Δ的严格包围|符号|
|---|---|---|
|6.8707275390625|[0.000006793548,0.000006793549]|正|
|6.871337890625|[−0.000003744042,−0.000003744041]|负|

0<a<b，故这是非零根。t=0时两模型都没有来得及灭绝，Δ(0)=0，但不是本次寻找的根。t→∞时两概率趋1，差趋0；无穷不是一个有限实数时间，不能把极限当额外根。最简单的提醒是exp(−t)始终正，却趋于零。

## 4. 区间和二分：不靠小数猜符号

若随机概率在[L_s,U_s]，对照在[L_a,U_a]，则差在[L_s−U_a,U_s−L_a]。只有下界>0才能断言正，只有上界<0才能断言负；若区间含零，可能是真零，也可能误差界过宽，不能猜。

二分保存一个不变量：左端严格正、右端严格负。取有理中点m=(a+b)/2，严格判出Δ(m)>0就移动左端，严格判出Δ(m)<0就移动右端。每次仍保留至少一个根，宽度减半。这里13次后宽度是5/2^13，不需要函数全程单调。

**二分没有给唯一性。** 原区间可以有三个根，二分仍可能一直保留其中一个；两个端点同号也不能断言没有根，例如(t−1)^2在两侧为正、在1处为零。

主程序只允许一次K=800后备精度，仍无法判符号就停止为不确定。下方最小版直接报错，不偷偷用浮点或增加无上限重试。

## 5. 完整最小可运行实验

只需Python标准库，无需安装包、密钥或网络。保存为minimal_e02.py，运行：

下面程序已真实运行，证书使用Fraction；最后float只用于显示时间，不参与分支判断。

```python
"""E02自包含严格根存在实验，仅需Python标准库。
运行：python -B minimal_e02.py
模型固定N=8、n0=4、两向环境速率1/10。输出区间认证存在，不认证全局唯一性。
"""
from fractions import Fraction as F
from math import ceil, lcm


def probability_bounds(t, averaged=False, K=400):
    t = F(t)
    deaths = (F(1),) if averaged else (F(1, 2), F(3, 2))
    environments = len(deaths)
    dead = 8 * environments
    rules = []
    for e, mu in enumerate(deaths):
        for n in range(1, 9):
            events = []
            if n < 8:
                events.append((e * 8 + n, F(n * (8 - n), 4)))
            events.append((dead if n == 1 else e * 8 + n - 2, mu * n))
            if not averaged:
                events.append(((1 - e) * 8 + n - 1, F(1, 10)))
            rules.append(events)
    D = lcm(*(rate.denominator for row in rules for _, rate in row))
    lam = ceil(max(sum(rate for _, rate in row) for row in rules))
    base = lam * D
    x = lam * t
    if t < 0 or K + 2 <= x:
        raise ValueError("时间非法或K不足")
    weights = []
    for state, row in enumerate(rules):
        events = [(target, int(rate * D)) for target, rate in row]
        events.append((state, base - sum(weight for _, weight in events)))
        assert all(weight >= 0 for _, weight in events)
        weights.append(events)
    weights.append([(dead, base)])
    counts = [0] * (dead + 1)
    for e in range(environments):
        counts[e * 8 + 3] = 1  # n0=4的索引
    coefficient = F(1, environments)
    numerator, a, total = F(0), F(1), F(1)
    mass = environments
    for k in range(1, K + 1):
        updated = [0] * len(counts)
        for state, count in enumerate(counts):
            for target, weight in weights[state]:
                updated[target] += count * weight
        counts = updated
        mass *= base
        assert sum(counts) == mass
        coefficient *= t / (D * k)
        numerator += coefficient * counts[dead]
        a *= x / k
        total += a
    tail = a * x / (K + 1) / (1 - x / (K + 2))
    return numerator / (total + tail), min(F(1), (numerator + tail) / total)


def delta_bounds(t):
    switch = probability_bounds(t)
    average = probability_bounds(t, averaged=True)
    return switch[0] - average[1], switch[1] - average[0]


if __name__ == "__main__":
    left, right = F(5), F(10)
    assert delta_bounds(left)[0] > 0
    assert delta_bounds(right)[1] < 0
    steps = 0
    while right - left > F(1, 1000):
        if steps >= 16:
            raise RuntimeError("达到冻结迭代上限")
        middle = (left + right) / 2
        low, high = delta_bounds(middle)
        if low > 0:
            left = middle
        elif high < 0:
            right = middle
        else:
            raise RuntimeError("区间含零，不能凭浮点猜符号")
        steps += 1
    assert 0 < left < right and right - left <= F(1, 100)
    assert delta_bounds(left)[0] > 0 and delta_bounds(right)[1] < 0
    print("严格根区间（有理端点）：", left, right)
    print("端点十进制：", float(left), float(right))
    print("宽度：", right - left, "=", float(right - left))
    print("二分步数：", steps)
    print("连续性+严格异号证明至少一个非零根；此最小程序不证明唯一性。")
```

```text

端点十进制： 6.8707275390625 6.871337890625
宽度： 5/8192 = 0.0006103515625
二分步数： 13
连续性+严格异号证明至少一个非零根；此最小程序不证明唯一性。
```

weights是“共同事件时钟”下的整数跳转权重，counts是所有可能路径的整数加权计数，**不是Monte Carlo样本数**。本轮没有新随机模拟，因此没有新随机种子。最小代码固定原参数；若改规则或初态，端点可能不再合格，需另定协议。

## 6. 最小代码的严格包围从哪里来

沿用E01均匀化。选λ≥最大离开率，P=I+G/λ的元素非负且行和1。记x=λt、a_k=x^k/k!、p_k为P走k步后的吸收概率。则真实概率为Σa_kp_k/exp(x)。

截断至K，记A=Σa_kp_k、S=Σa_k。由于0≤p_k≤1，当K+2>x时，指数尾和概率分子尾均不超过

\[
B=\frac{a_{K+1}}{1-x/(K+2)}.
\]

理由是K+1之后相邻项比例至多x/(K+2)<1，余项被几何级数控制。因此概率在[A/(S+B), min(1,(A+B)/S)]。

D是各事件速率分母的公倍数，整数基数L=λD。走k步后，计数对应分母mL^k，m为等权初始环境数。乘上a_k后，系数化为t^k/(mD^k k!)。代码每步核对总计数恰为mL^k，所有分支和包围运算都是任意精度整数/有理数。

本模型随机链λ=13、D=20、L=260；平均链λ=9、D=4、L=36；K=400。这是有限模型的计算保证，仍依赖实现正确；没有形式化验证或现实参数保证。

## 7. 新增控制：这个小区间内为什么唯一

令p(t)为完整行概率向量，f为吸收态指示。F'(t)=p(t)Gf。只有n=1的死亡会立即流入吸收态，所以h=Gf在(n=1,e)处是μ_e，其他处为0。

直觉上F'是此刻流入灭绝的概率速度，也叫吸收通量。它是非负函数的期望。随机链的h最大为3/2，不是概率上限1；因此扩展证书必须使用M=3/2。

更一般地，若0≤h≤M，均匀化分子遗漏尾≤MB，便有

\[
\frac{A_h}{S+B}\le E[h(X_t)]\le
\min\left(M,\frac{A_h+MB}{S}\right).
\]

分别包住两链通量再相减，就严格包住Δ'(c)。这与概率证书属于同一数学方法，不额外冒充另一独立验证算法。

还必须控制整个区间，不能只看中点斜率。有限链有F''(t)=p(t)G²f，概率加权平均的绝对值不超过向量分量绝对值的最大值。逐事件精确计算给

\[
\|G_s^2f_s\|_\infty=199/40,
\quad \|G_a^2f_a\|_\infty=11/4,
\quad |\Delta''(t)|\le L=309/40.
\]

由微积分的变化速度界，在中心c、半宽r=(b−a)/2处，对全部t∈[a,b]有

\[
|\Delta'(t)-\Delta'(c)|\le Lr.
\]

本轮精确中点导数包围加减Lr后，向外舍入得到

\[
\Delta'(t)\in[-0.019622269926,-0.014907304105]
\quad(\forall t\in[a,b]).
\]

全区间严格负，故Δ严格递减，至多一个根；前面的存在证明给至少一个，两者合起来才是**该区间内恰有一个根**。没有覆盖[0,a)或(b,∞)，不能推出全局唯一，也没证明它是第一个根。

此进阶部分不在最小程序里；完整通量证书、二阶导数向量和独立实现未收入本目录。

## 8. 固定容量，仅改初始人数

下表的N、死亡系数、出生规则和ν都不变。数值是严格有理差区间的近似显示，符号由区间认证。

|初始人数|Δ(5)|Δ(10)|本轮能说什么|
|---|---:|---:|---|
|1|−0.04697339|−0.07104549|这两点为负，不说明所有时间都负|
|2|−0.01676170|−0.06692307|与4个体的t=5方向不同|
|4|+0.03398019|−0.04376544|主认证根位于(5,10)|
|8|+0.06692686|−0.02546391|连续性给(5,10)至少一根，未定位/计数|

为什么初态会影响方向？设最初m个个体，m≥2。在极短时间内灭绝，最少需要m次死亡；出生或切换会增加事件数，只在更高阶出现。给定固定初始μ，最短路径速率积是m!μ^m，时间排序积分给t^m/m!，所以首项为μ^m t^m。随机与平均之差为

\[
\Delta(t)=\left(\frac{(1/2)^m+(3/2)^m}{2}-1\right)t^m+O(t^{m+1}).
\]

括号对m≥2为正。对m=4恰为25/16。这里O(t^(m+1))表示存在有限常数C，在充分小的时间余项绝对值≤Ct^(m+1)；它不自动宣称任意具体t已经足够小。本轮另以精确区间检验t=.01，m=4时Δ约1.4696×10^-8>0。

m=1的一阶差为零，必须看二阶。两模型共同出生项抵消，平稳环境的切换项平均抵消，剩下死亡系数方差：Δ(t)=−Var(μ)t²/2+O(t³)=−t²/8+O(t³)。t=.01的精确Δ约−1.2085×10^-5。不能只套m≥2的一句话。

精确G幂另核对了首项：m=1是−t²/8，m=2是+t²/4，m=4是+25t⁴/16，m=8是+3025t⁸/256。m=2短时正而Δ(5)严格负，所以连续性还给(0,5)至少一根；本轮没有另搜它的位置。短时解释不等于全时间机制定理。

# E02 关键证明独立复核

## 1. 固定模型与方向

N=8，出生率 \(b_n=2n(1-n/8)\)，死亡率 \(n\mu_e\)，\(\mu_0=1/2,\mu_1=3/2\)，两向切换率 \(\nu=1/10\)。初始环境等权，且初始人数固定。平均链保留出生率、人数和吸收边界，死亡系数 \(\bar\mu=1\)。

G 的行是出发状态，列是到达状态；每行和零，非对角非负。完整概率是**行**向量 \(p(t)=p(0)e^{tG}\)。观察量 f 是吸收态指示**列**向量。因此
\[
F(t)=p(t)f,\quad F'(t)=p(t)Gf,\quad F''(t)=p(t)G^2f.
\]
G 作用于列观察量，p 从左乘 G；这里没有把 \(G^\mathsf T\) 偷换进来。吸收态合并环境合法，因为灭绝后两个环境对“已经灭绝”的观察量完全等价。

## 2. m=1 的二阶项

令 \(h=Gf\)。h 只在 n=1 时非零，值为 \(\mu_e\)。由于 \(b_1=7/4\)，直接按事件列出
\[
(Gh)(1,e)
=b_1(0-\mu_e)+\mu_e(0-\mu_e)
+\nu(\mu_{1-e}-\mu_e).
\]
初始环境等权时，切换贡献相加为零；故随机链
\[
F_s(t)=\bar\mu t-\frac12\{b_1\bar\mu+E(\mu^2)\}t^2+O(t^3).
\]
平均链为
\[
F_a(t)=\bar\mu t-\frac12\{b_1\bar\mu+\bar\mu^2\}t^2+O(t^3).
\]
两者相减，出生贡献抵消，\(E(\mu^2)=5/4\)，因此
\[
\Delta(t)=-\tfrac12\operatorname{Var}(\mu)t^2+O(t^3)
=-\tfrac18t^2+O(t^3).
\]
这成立于既定模型，未把出生忽略。对非平稳初始权重 \(\pi\)，若对照用该初态均值，二阶差一般多出
\(\frac12\nu E_\pi(\mu_{\rm other}-\mu)t^2\)。
最小条件反例：初始必在好环境、对照 \(\bar\mu=1/2\)，方差为零，但切换贡献使二阶差为 \(+t^2/20\)。这是检验条件的代数边界例，不是改变本轮主模型。

## 3. m≥2 的最少路径系数

到达零必须净减少 m。每次死亡最多减少1；出生增加1；切换和对角停留不减少人数。因此在 \(G^k f\) 的矩阵路径展开里，k<m 的吸收贡献为零；k=m 时仅有 m 次连续死亡可达零，不能插入出生、切换或对角项。

该路径速率积为 \(m\mu_e(m-1)\mu_e\cdots\mu_e=m!\mu_e^m\)。矩阵指数的 \(1/m!\) 恰好抵消。等价的有序事件时间单纯形体积为 \(t^m/m!\)，且短时生存因子为 \(1+O(t)\)。所以
\[
F_s(t)=E(\mu^m)t^m+O(t^{m+1}),\quad
F_a(t)=\bar\mu^m t^m+O(t^{m+1}).
\]
对本模型所有整数 2≤m≤8，\(E(\mu^m)-1>0\)。独立矩阵有理幂逐一检查 m=1…8，首项系数依次为
\[
-1/8,\quad1/4,\quad3/4,\quad25/16,\quad45/16,\quad301/64,\quad483/64,\quad3025/256.
\]
第一项阶数2，第二至第八项阶数分别2至8。这是有限维代数核验，没有新增生态参数网格。解析余项说明“充分小的 t”时符号，不自动给具体 t 的阈值。

## 4. \(309/40\) 从何而来

逐事件计算 \(G^2f=Gh\)：

|状态|随机链分量|平均链分量|
|---|---:|---:|
|n=1，好|−41/40|−11/4|
|n=1，坏|−199/40|不适用|
|n=2，好|1/2|2|
|n=2，坏|9/2|不适用|
|n≥3 或吸收态|0|0|

n=2 项来自死亡率 \(2\mu_e\) 乘 n=1 观察量 \(\mu_e\)，为 \(2\mu_e^2\)。切换在 n=2 时连接的 h 都为零。

这里 \(\|G^2f\|_\infty\) 是**列向量最大分量绝对值**，不是把矩阵的行和与列和混用。p(t) 非负且总和1，故
\[
|p(t)G^2f|\le\sum_i p_i(t)|(G^2f)_i|
\le \max_i|(G^2f)_i|.
\]
由三角不等式，对全部 t≥0，
\[
|\Delta''(t)|\le199/40+11/4=309/40.
\]
这个界保守而有效，不声称最优。
