## 核心结果：不同误差指标分别判断

主例有两个位置、两个环境。以下界覆盖所有初始微状态；CDF 界覆盖所有时间：

- 首达时间 CDF 的绝对误差 ≤ min(1, 49/(18ν))。误差不超过 1% 的充分阈值为 ν ≥ 2450/9 ≈ 272.2222。
- 首达时间均值的相对误差另有证书：ν ≥ 608458/4095 ≈ 148.5856 时不超过 1%。这个阈值不能替代 CDF 阈值。
- ν=300 时，均值相对误差的认证上界为 10201/2448684 ≈ 0.00416591；生存尾界的指数衰减率为 58302/40517，各初态对应的前置系数见结果文件。
- 充分证书未通过，只表示“未认证”，不能据此断言平均化失效或真实均值无穷。

CDF 定理要求：有限、齐次、保守且不可约的快块；目标由完整快块组成；合法的杀死生成矩阵；以及所选全时间界需要的瞬态性或衰减条件。均值证书额外要求修正向量 v 和 g 逐项严格为正。可执行的精确入口仅覆盖一至两个慢状态、每个慢状态两个环境、共用正环境切换速率的小模型。

这些是既有平均化、可聚合性、Poisson 修正和 Lyapunov 比较方法的教学应用。新颖性未建立。算法交叉校验不等于独立同行审稿。

## 只用 Python 标准库复算

在本目录运行。不要使用 Python 的 `-O` 选项，它会禁用断言检查。

```sh
python3 -B mean_minimal.py
python3 -B cdf_certificate_exact.py
python3 -B audit_exact.py
python3 -B repair_probes.py
python3 -B mean_exact.py
python3 -B validate_mean.py
```

最小例子完全独立。其他精确脚本共用 `audit_exact.py` 中的 Fraction/Cramer 工具；审查程序以两环境中心化解析式与 Cramer 法交叉验证，最小例子则使用高斯消元。最后的比较程序把刚重算的精确均值与随包保留的历史浮点结果比较，并不重新运行浮点求解器。

可选：`mean_float.py` 使用 NumPy/SciPy 独立构造并求解六组均值算例。历史版本为 NumPy 2.3.5、SciPy 1.17.0。先运行它，再运行 `validate_mean.py`，即可重新生成并比较两条路线。本公开版整理时没有安装依赖或重跑浮点求解器。

## 证据与已知更正

`results/` 包含本次精确审查、精确均值、回归探针及运行日志，也保留了历史浮点均值、CDF 网格摘要和抽取的精确代数证书。再次运行脚本会覆盖它对应的结果文件。

旧浮点演示把小于 1e-12 的残差视为精确零，不适合通用严格认证。公开版 CDF 入口改用精确有理数、拒绝浮点输入，并在回归例中保留微小但非零的误差界。历史原模型的有理证书独立支持上述主例常数，不依赖有缺陷的容差判零。

本精简版不包含密集 CDF 曲线、图像或完整历史 776 点有理概率包络网格，因此不提供该历史网格的完整重跑入口。完整数学推导及上列公开复算命令所需的全部代码依赖均已包含。
